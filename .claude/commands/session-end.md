---

今日のセッションを締める。以下を順番に実行すること。

## 手順

### 1. 今日の作業を振り返る
- `git log --oneline -10` と `git status` で、このセッションでの変更を整理する

### 2. docsの更新
- 仕様（画面・機能・データ形式）に変更があれば `docs/SPEC.md` を更新
- 計画・フェーズ・意思決定に変化があれば `docs/ROADMAP.md` を更新（意思決定の記録テーブルへの追記を忘れない）
- 変更がなければスキップしてよい

### 3. メモリへのセッション記録
- メモリディレクトリに `project_session_YYYY_MM_DD.md`（同日2回目は末尾b）を作成:
  - 今回やったこと（簡潔に）
  - 未完了・持ち越しの作業
  - **次回やることの候補**（次のセッションが迷わず始められるように具体的に）
- `MEMORY.md` のインデックスに1行追加する

### 4. 最終報告
- 未コミットの変更が残っていれば必ず報告する（勝手にコミットしない。コミットするか岡田さんに確認）
- 今日の成果と次回の開始ポイントを2〜3行でまとめて報告する
