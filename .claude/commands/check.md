drink-counterの品質チェックを行う。問題を見つけても勝手に修正せず、まず一覧で報告すること（修正するかは岡田さんが決める）。

## チェック項目

### 1. 静的チェック
- `npm run lint` — エラー・警告を報告
- `npm run build` — ビルドが通ることを確認

### 2. コードの衛生チェック（src/ を対象にGrep）
- `console.log` / `debugger` の残り
- `TODO` / `FIXME` コメント
- 使われていない変数・コンポーネントの形跡

### 3. 仕様との整合チェック
- `docs/SPEC.md` を読み、現在の `src/App.jsx` の実装と食い違っている箇所を洗い出す
- 実装が先に変わってSPECが古い場合は「SPEC更新が必要」として報告

### 4. 実機確認チェックリストの出力
最後に、岡田さんがスマホ（iPhone Safari / PWA）で確認すべき項目を出力する:

- [ ] ホーム画面: キャラクターとボタンが中央に表示され、左右ずれがない
- [ ] カウンター画面: ＋/−が正しく動き、0未満にならない
- [ ] 吹き出し: 2/4/6/8杯ちょうどで表示され、3秒で消える
- [ ] 振り返り: 会話が最後まで進み、終了後に記録が保存される
- [ ] 記録画面: 過去の記録が日付つきで表示され、タップで会話が展開される
- [ ] 画面遷移: ホーム→カウンター→振り返り→ホームが一周できる
- [ ] PWA: ホーム画面アイコンからスタンドアロンで起動する

（チェックリストは変更内容に応じて関連項目を絞ってよい）
