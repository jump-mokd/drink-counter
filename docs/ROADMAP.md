## フェーズ1: フィードバック収集（現在）

ゴール: 「誰が・どんな場面で使うか」の実データを得て、ネイティブ化と収益化の設計に活かす。

- [ ] Vercel Analyticsのデータ確認（訪問数・リピート・利用時間帯）
- [ ] テスターからのフィードバック収集と課題リスト化
- [ ] フィードバックに基づく小さな改善（バグ修正・文言調整など）

## フェーズ2: PWA改善（フィードバック反映）

MVP定義時に「後回し」とした項目。**着手はフィードバックの裏付けが出てから。**

- [ ] キャラクターのアニメーション強化（動き・表情変化）
- [ ] 吹き出しセリフパターンの拡充
- [ ] SNSシェア機能（振り返り結果を画像でシェア → 口コミ集客）
- [ ] 金額計算機能（1杯の単価設定 → 合計金額表示。無料提供で集客）

## フェーズ3: ネイティブ化・ストア公開準備

- [ ] **Capacitorでのネイティブ化**（既存Reactコードをほぼそのまま流用）
- [ ] **データ永続化の強化**（localStorage → 必要に応じてSupabase等のDB）
- [ ] **プライバシーポリシー整備**（ストア審査で必須）
- [ ] **アルコール関連アプリのストアガイドライン確認**（特にApple。年齢制限等）
- [ ] アプリ名・アイコンのブランディング強化（LINEスタンプ展開と世界観を統一）
- [ ] キャラクターの命名

## フェーズ4: 収益化

前提: ユーザー認証（Supabase Auth / Firebase Auth等）が必要になる可能性が高い。

| モデル | 概要 | 難易度 |
|--------|------|--------|
| キャラクタースキン販売 | 番犬の見た目・セリフを差し替える有料スキン | 中（デザインコスト） |
| サブスク（月300〜500円） | 記録・統計・予算管理などPro機能 | 高（機能開発コスト） |
| 金額計算機能で集客 | 無料提供してユーザー獲得（フェーズ2参照） | 低 |

- [ ] Analyticsデータをもとに収益化モデルを1つ選定
- [ ] ユーザー認証の導入（課金状態の紐付けに必要）
- [ ] LINEスタンプ展開の検討
