# ドリンクカウンター 仕様書

最終更新: 2026-06-12（MVPリリース版の実装を反映）

## 1. コンセプト

バー・キャバクラ・ホストクラブなど夜の接客店で、**自分と相手（接客スタッフ）が何杯飲んだかをカウントする**Webアプリ。

看守の制服を着た番犬キャラクター（看守番犬）が杯数を監視し、閾値を超えるたびに罵倒コメントで罪悪感を与え、飲みすぎ・奢りすぎを防ぐ。

- **メインターゲット**: 夜の接客店に来るお客さん
- **将来**: 一般飲み会への展開も視野（強制はしない）
- **キャラクター**: 将来的にLINEスタンプ展開を想定したブランドマスコット

## 2. 画面構成と遷移

```
ホーム ──[飲み始める]──→ カウンター ──[飲み終える]──→ 振り返り ──[ホームへ戻る]──→ ホーム
  │                        │
  └─[記録を見る]──→ 記録 ←─[📋アイコン]
       （←で元の画面に戻る）
```

状態管理は `App.jsx` 内の `screen` state（`'home' | 'counter' | 'review' | 'history'`）。ルーターは未使用。

### 2.1 ホーム画面（HomeScreen）
- アプリタイトル + 看守番犬キャラクター（大）
- 「飲み始める」→ カウンター画面へ
- 「記録を見る」→ 記録画面へ
- ホームに戻るたびにカウントは0にリセットされる

### 2.2 カウンター画面（CounterScreen）
- 「相手」「自分」2つのカウンターカード（＋／−ボタン、0未満にはならない）
- 合計杯数の表示
- 「リセット」: 両カウントを0に戻す
- 「飲み終える」→ 振り返り画面へ
- ヘッダー右の📋アイコン → 記録画面へ
- 画面下部に看守番犬キャラクター常駐。コメント発火時に吹き出し表示

### 2.3 振り返り画面（ReviewScreen）
- 番犬とのチャット形式の会話。杯数に応じた質問スクリプトを順に提示
- ユーザーは選択肢ボタンで回答 → 番犬がリアクション → 次の質問
- 会話終了時に**記録をlocalStorageへ自動保存**
- 「ホームへ戻る」でカウントをリセットしてホームへ

### 2.4 記録画面（HistoryScreen）
- 保存された記録を新しい順にカード表示（日付、自分/相手の杯数）
- カードタップで振り返り会話の全文を展開/折りたたみ
- 記録がない場合は「記録がありません」
- ←ボタンで遷移元の画面（ホーム or カウンター）へ戻る

## 3. 看守番犬キャラクター

- インラインSVGで実装（`GuardDogCharacter` コンポーネント、外部ファイルなし）
- ちびキャラ体型。看守制服（ひさし付き帽子・バッジ・肩章・濃紺ユニフォーム）+ 警棒
- 表情は常に険しい顔で固定（変化なし）
- 名前: 未定（デザイン確定後に命名予定）
- 表示サイズ: ホーム/カウンターでは大（210x203）、チャットのアバターでは小（48x46）

### 3.1 コメントシステム（カウンター画面）

- 「自分」「相手」を独立して監視
- カウントが閾値（2, 4, 6, 8杯）に**ちょうど達した時のみ**発火（−で戻して再度＋した場合も発火する）
- 各閾値につき3パターンのセリフからランダム選択（`SELF_COMMENTS` / `HER_COMMENTS`、計24種）
- 吹き出しは**3秒後に自動消去**。連続発火時はタイマーをリセットして上書き

| 対象 | 主旨 |
|------|------|
| 自分 | 飲みすぎ警告（例: 「おい…もう2杯目か」） |
| 相手 | 奢らせすぎ・カモ警告（例: 「4杯か。完全にカモにされてるぞ」） |

### 3.2 振り返りスクリプト（getReviewScript）

杯数に応じて質問を動的に組み立てる:

1. **自分の杯数**で分岐: 8杯以上（2問・帰宅確認あり） / 4〜7杯（2問） / 3杯以下（1問）
2. **相手の杯数**で追加: 7杯以上（財布の心配） / 4〜6杯（コスパ確認） / 3杯以下は質問なし
3. 締めの質問「また来るつもりか？」は常に最後に出る

各質問は2〜3個の選択肢を持ち、それぞれに番犬のリアクションが対応する。

## 4. データ仕様

### 4.1 保存先

localStorage（キー: `drinkHistory`）。MVP段階ではサーバー・DBなし。

### 4.2 記録レコードの形式

```json
{
  "id": "1746...（Date.now()の文字列）",
  "date": "2026年5月3日(土)",
  "myCount": 4,
  "herCount": 2,
  "conversation": [
    { "from": "dog",  "text": "かなり飲んだな。何か言い訳はあるか？" },
    { "from": "user", "text": "ストレス解消" }
  ]
}
```

- 配列の先頭が最新（新しい記録をunshift）
- 読み込み失敗時は空配列にフォールバック
- **カウント中の杯数はあえて永続化しない**（リロードで消えてよい、というMVP定義に基づく）
